# Brand marks

Logos are the brands' own; they identify where a ledger row or an account comes from. Raster
icons are downscaled to 96 px. Revolut, Binance and Claude are inline paths in
`components/SourceMark.tsx`, not files here.

| Mark | Source |
|---|---|
| `mono.png` | monobank.ua, the site icon (`/assets/icon-*.png`) |
| `splitwise.png` | splitwise.com, `/apple-touch-icon-precomposed.png` |
| `ibkr.png` | interactivebrokers.com, `/images/web/favicons/home-screen-icon-192x192.png` |
| `zenmoney.png` | zenmoney.app, `/images/webclip.ico` (the PNG inside) |
| Revolut, Binance, Claude | Simple Icons 16.37.0 (CC0), `icons/{revolut,binance,claude}.svg` |
